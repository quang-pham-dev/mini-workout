# Phase 06 — Handoff

## Goal

Make the result easy for another teammate to understand, verify, and continue.

## Required report

- concise summary of user-visible and technical changes;
- files/workspaces changed;
- checks run with results;
- migrations, environment variables, or rollout steps;
- known limitations, risks, and follow-ups;
- screenshots or test artifacts for UI/browser changes.

For a feature, link the execution plan and any decision record. Mark the task
as complete only after all acceptance criteria have evidence or are explicitly
listed as blocked.

Use conventional commit wording when preparing a commit, but do not commit,
push, or open a pull request unless explicitly requested.
